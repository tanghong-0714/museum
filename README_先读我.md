# 重器新生 · 队友完整交付包（含 API 服务与配置模板）

## 怎么打开

1. 将整个 ZIP 解压到本地普通目录，例如 `D:\Museum`。不要直接在压缩软件里运行。
2. Windows 10/11 64 位系统，双击 `启动整个项目.cmd`。已附 Node 24.11.1 和运行依赖，首次运行不需要 npm 安装。
3. 等待显示“启动完成”，浏览器会打开 http://127.0.0.1:5192/ 。启动窗口需要保持打开。
4. 结束时在启动窗口按 Ctrl+C，或双击 `停止整个项目.cmd`。停止脚本只处理本目录记录的服务进程。

展厅：5192；文物展示：5189；修复/照片建模工作台：http://127.0.0.1:4317/images 。这三个模块一起启动才可以完整跳转。端口被占用时会提示，不会关闭别人的服务。

## 账户和密钥

参观默认建立游客身份，不强制注册。游客与打卡记录保存在队友本机，浏览器清除数据或更换电脑不会自动同步。没有一个需要向作者索取的默认登录密码。

本包不含个人 API 密钥。请将 workbench/.env.example 复制为 workbench/.env，将 artifacts/.env.example 复制为 artifacts/.env.local，填入接收者自己的 Tripo、生图、DeepSeek 等密钥。未配置时仍可参观现有文物；在线生成、建模和问答需要配置后使用。

模型展示可本地运行；在线 AI 需要联网、服务余额和服务可用。此次交付不通过付费生成来测试密钥余额或可用性。

## 包里有什么

- `hall`：当前展厅源码、完整公共素材、已构建网页和运行依赖。
- `artifacts`：文物展示源码、11 件文物模型/资料、原始模型、已构建网页、API 后端和运行依赖。
- `workbench`：修复与照片建模工作台源码、现有图片/四视图/模型/分析历史及配置模板。
- `Blender源文件`：最新 R18 可编辑展厅。部分展柜修正、工具和交互由网页 JS 运行时生成，没有烘焙进 Blender。
- `runtime`：Windows x64 Node 及许可证。
- `verification`：交付验证记录和文件校验清单。

保留全部当前运行素材与原始文物模型；未附旧交付压缩包、旧代码备份、Git 历史、调试截图/日志、浏览器登录缓存及原游客账户数据库。旧临时图片会按工作台已有的 24 小时清理规则清理，已完成模型保留。当前展厅陈列与文物库数量不同，以各模块现有配置为准。

## 手机扫码与异地访问

这是本地运行包，不是已经部署的公网网站。默认仅本机访问。队友在自己的电脑解压启动即可体验；其他手机扫到 127.0.0.1 不会连接到这台电脑。需要另行配置局域网网关或正式域名，再生成对应二维码；没有沿用作者电脑的旧热点 IP。

## 继续开发

已保留原 package.json 和 package-lock.json。安装 Node >=24.11 后，在对应模块运行 `npm ci`，即可补齐开发依赖。

展厅 `npm run build` 输出 `hall/dist`；文物页输出 `artifacts/release_R10`。修改后重新构建并重启启动脚本。工作台修改服务代码后重启；模型查看器源码修改后运行 `npm run build:viewer`。

本交付副本适配：文物页默认返回展厅指向 5192；模型代理支持启动脚本提供的工作台地址；启动使用轻量 Node 服务承载构建网页和原有后端，避免 Windows 对构建工具原生组件的拦截。原项目没有被这些打包适配修改。开发时仍可使用原有 Vite 工作流。

如页面加载旧缓存，使用 Ctrl+F5。运行脚本显示端口占用，先关闭已有实例；不要删除模型目录来解决启动问题。

# 拾遗：文物复原与三维工作台（本地 R11）

## R11 上下左右视图与等待效果（当前）

四视角现在指俯视、仰视、左侧、右侧。每张以同一复原图为参考，通过 LK 图像服务分别生成；费用为 4 次生图用量。支持单独重做某个视角，保留其他满意方向及旧版本的模型来源。完全相同的图片会被拦截，但这不是完整的视觉一致性鉴定。

当前 Tripo API 只支持 front/left/back/right 输入，因此此流程建模提交复原主图作为 front，加上 left/right 两张图；上下图用于审阅，不冒充 front/back。原生前左后右旧任务继续保留，修复了其真实响应的嵌套字段解析，可查询找回已生成图片。

分析、生图与四视角生成提供扫描动效、真实阶段、已等待时长和逐张结果。建模阶段用参考图采样的轮廓粒子由散到聚，GLB 加载完后淡出到真实模型。粒子仅为等待动效，不表示已重建几何。支持系统“减少动态效果”。测试页面有醒目模拟标识，正式页面无该标识。

验证见 `四视角与等待动效验证_R11.md`。下方 R10 的“前左后右”生成说明为旧接口记录。

## R08 当前流程

上传照片后自动调用 DeepSeek 识别缺损，拟定修复方案和提示词，并自动填写器物与视角假设。用户阅读左侧提示词后点击“生成复原图”；满意后点击图下“满意，开始建模”，直接提交当前图并进入模型页。无需手动采用提示词、填写结构判断或二次确认。专业选项可展开修改；完整发送要求自动预览并绑定实际请求。

上传分析、点击生图、点击建模分别产生对应服务商用量。刷新和切换页签不会新建任务。原图、旧草稿和生成记录继续保留。当前验证见 `流程简化验证_R08.md`。以下 R06/R07 为历史记录，旧手动流程已由 R08 取代。

## R07 工作台布局

- 图像页：左侧独立滚动的资料与参数、中间常驻原图/复原图、右侧方案/AI 分析/版本。并排、原图、复原图三种显示可切换，版本可按名称或要求搜索。

- 保留 R06 的文物草稿隔离、原图追溯、结构核对和收费前完整请求预览。分析与建模不会因切换面板而自动提交。

## R06 复原流程修复

- 每件文物使用独立草稿；“修复另一件文物”清空照片、提示词与分析，不继承上一件器物的要求。旧任务可切回。
- 复原前选择器物类别、原图视角、成品视角和补全目标。采用 AI 分析前明确结构判断或本次采用的假设；不同文物或不同原图的分析不能直接采用。
- 按盘碟、瓶罐、雕塑分别组织提示词，保留结构疑点，不再给所有器物套用人物雕塑规则。
- 已知生成图重新上传时按文件内容识别，并尽可能追溯原始照片；原图优先，AI 图只作为辅助。该识别仅覆盖本地已知结果的相同字节文件，不是通用 AI 鉴图。
- 点击“预览完整要求（不收费）”先核对实际参考图及全部提示词；再点击“确认生成（收费）”才提交。预览后请求内容变化需重新预览。
- 新生成记录保存实际发送的完整提示词。旧记录未保存的历史请求不作补造；原图与历史结果不覆盖。

## 启动

需要 Node.js 24.11 或更新版本。后端使用 Node 内置模块，前端 Three.js 已打包到本地，直接运行无须 npm install。修改三维查看器源码时才需要 npm ci 和 npm run build:viewer。

在本目录执行 `npm start`，或双击 `启动工作台.cmd`。

- 生图工作台：http://127.0.0.1:4317/images
- 三维工作台：http://127.0.0.1:4317/models
- Tripo 连接测试：http://127.0.0.1:4317/

## 配置

复制 `.env.example` 为 `.env`，填入自己获授权的密钥：

```dotenv
TRIPO_API_KEY=
LK_IMAGE_API_URL=https://api.lk888.ai/v1
LK_IMAGE_API_KEY=
DEEPSEEK_API_KEY=
```

修改配置后重启服务。图像密钥仅由后端读取，不发送到网页。更新或清除 Tripo 密钥会保留同文件中的 LK 设置。项目不修改 Windows 全局环境变量，不执行分享包中的安装脚本。

LK 凭据固定发送到 https://api.lk888.ai/v1，模型标识为 tt-image-2.5；不自动切换供应商。

## 使用

1. 上传一张破损照片，等待 AI 自动分析并填好修复提示词。最多可加 4 张参考，单张 10 MB。
2. 阅读提示词，可选修改；点击“生成复原图”提交一次生图任务。
3. 审阅结果。满意后点击“满意，开始建模”，直接提交当前图；默认使用网页流畅、5 万面上限。更高精度可在模型页选择。
4. 在模型页旋转查看、下载 GLB，或人工标记补全示意并导出成品 PNG。

其他模式、AI 结构判断、画面设置、完整请求和历史分析均为可选入口。
原图、结果及任务记录位于 data/images/，页面刷新和服务重启后可读取历史。原文件不会被新结果覆盖。文物草稿保存在当前浏览器 localStorage，不含密钥；当前标签页选择保存在 sessionStorage。没有跨浏览器或跨设备草稿同步，清除浏览器数据会丢失草稿，不影响服务器历史。

## 接口和能力边界

- 只读检查：GET /v1/models。
- 文生图：POST /v1/images/generations。
- 编辑：POST /v1/images/edits。单参考图字段 image，多参考图字段 image[]。
- 任务查询与找回：GET /v1/media/status?task_id=...。
- 每次输出 1 张 PNG，不支持局部蒙版或单请求多张输出。
- 复原模式按器物类别补充结构与保留约束，但不保证未损伤区域像素不变或符合历史真实原貌；明确的用户假设也可能判断错误。
- 模型名是中转服务标识，不代表已独立核实底层模型身份。
- 三维补全区由人工点选标记，不是自动识别、精确网格分割或可与实物拼接的补片。原图上的二维高亮编辑器尚未实现。
- 没有原始扫描网格，不能承诺保持原三维几何；背面和内部为推测。
- Three.js 支持自包含 GLB 与 meshopt；外部资源引用被拒绝。压缩扩展或 WebGL 不支持时可以下载原始 GLB。
- 成品图直接渲染当前三维模型，保证显示对象一致；不是额外生成的真实照片。

## 超时与重复计费保护

收费请求最长等待 600 秒，只允许 1 个任务同时执行，不自动重试 POST。本地请求编号用于去重；提交状态不明时可核对同一请求。

超时、断线或服务中断后，任务可能已执行或计费。收到服务商任务编号时，可点击“查询并找回任务结果”，该操作不重新生成；没有编号时，请先到服务商后台核对再决定是否重提。

## 三维任务与保存

国内 API：POST /v3/files → POST /v3/generation/image-to-model → GET /v3/tasks/{task_id}。生成 POST 只发送一次；每 2 秒查询，最多自动查询 30 分钟。连续 3 次查询失败后暂停，可继续查询已有任务。服务重启后未完成任务标为待确认，需点击继续查询。

模型保存到 data/models/{本地任务号}.glb，历史和标记位于 data/models/state.json。模型下载地址不保存到公开记录，完成后立即取回本机；下载不携带 API 密钥。同一方案与精度复用未失败的已有任务，避免重复扣费。

三维验证记录见 三维建模验证记录.md。精度与真实性仍需逐件人工审阅。

## DeepSeek 图片分析与提示词预览（R04）

在 `.env` 添加 `DEEPSEEK_API_KEY` 后重启。固定使用官方 https://api.deepseek.com，调用模型为 `deepseek-flash`。官方当前对应 DeepSeek-V4.1-Flash-1017；旧的 V4 Flash 名称已由官方迁移到当前 Flash，本项目不假称调用退役版本。

- 左侧“分析原图”：读取编辑区上传的 1—4 张参考图和已有要求，返回可见特征、保留约束、不确定性、人工核对位置和完整提示词。
- 右侧“对比原图”：针对当前展示的成功复原任务，把该任务参考图与生成结果同时交给 DeepSeek，返回问题依据、建议及替代提示词。文字生图因无原图不能使用该对比。
- 下方分析区：显示实际送去分析的图片、历史与可编辑提示词；“采用此提示词与原始参考图”只填回编辑区，不提交生图/建模。复核提示词默认仍使用原始参考图片，避免以错误结果作为唯一依据。
- 分析记录位于 `data/analysis/state.json`，含模型返回标识、用量、耗时、图片编号与结构化结果，不保存密钥、图片 base64 或模型推理过程。编辑过的预览在当前浏览器会话中保留。
- API：GET `/api/analysis/status`、GET `/api/analysis/jobs`、GET `/api/analysis/jobs/{id}`、POST `/api/analysis/check`（只读模型列表）、POST `/api/analysis/jobs`（收费视觉分析）。
- 每次仅一个分析任务；相同提交编号去重；120 秒超时后标为待确认，不自动重试。重启不自动重复分析。分析费用按 DeepSeek 实际 token 用量计，模型未返回金额时不伪造费用。
- 目前提供文字比例分析和人工核对点建议，未实现自动精确测量、关键点圈选或蒙版修复。器形与历史真实性需要人工核对，不能用模型评价代替考古鉴定。

验证见 `DeepSeek接入验证记录.md`。评委包排除 `.env` 与全部私有图片/分析历史。

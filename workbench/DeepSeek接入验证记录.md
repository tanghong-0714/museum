# DeepSeek 图片分析与提示词助手 R04

日期：2026-11-05，北京时间。服务仅在 127.0.0.1 本机运行，未发布。

## 接入与配置

- 官方接口：https://api.deepseek.com/models；https://api.deepseek.com/chat/completions。
- 用户授权提供的密钥仅写入被忽略的 `.env` 中 `DEEPSEEK_API_KEY`，保留 LK 和 Tripo 配置；不进入网页脚本或源码包。
- 实际 GET /models 返回 HTTP 200，列出 deepseek-flash 和 deepseek-v4-pro。
- 调用名称为 deepseek-flash，官方文档称当前对应 DeepSeek-V4.1-Flash-1017；旧 V4 Flash 名称被官方迁移到当前 Flash。实际响应的 model 字段为 deepseek-flash，不自行伪造底层版本。
- 请求使用 user 消息中的 base64 image_url；JSON 输出；thinking disabled；max_tokens 4000；120 秒超时。单次请求不自动重试。
- 官方依据：https://api-docs.deepseek.com/ 、https://api-docs.deepseek.com/guides/vision 。

合计 10814 tokens。服务商未在响应中返回实际货币金额，不将估算费用冒充实际扣费。均成功解析并保存；本轮未调用 LK 生图或 Tripo 建模。检查前后生图任务均为 3 条、模型任务均为 1 条。

首次比较存在对缺失口沿与胖瘦的过度断言，因而补充了“共同可见部位对齐尺度”“未见不等于不存在”“缺失部位列为不确定”的提示约束。后续比较将下腹、底足、整体胖瘦列为 uncertain。模型仍可能判断错误，不能据此承诺解决所有比例问题。

补充规则明确完整成品图不默认加修补线、色差或高亮。这是提示约束，并非确定性图像修复保证；真实样本的预览提示词另经人工核对和修改，以验证可编辑流程。

## 已验证操作

- 右侧浏览器生图页出现原图分析、复原图比较、分析历史、可编辑提示词与采用按钮。
- 原图分析真实送出一张原始参考；比较真实送出该任务原始参考与对应生成结果。
- 页面列出所用图片、来源类型、模型返回标识、用量、耗时、可见特征、保留约束、不确定性与问题依据。
- 修改预览提示词后刷新，当前会话草稿保留；服务重启后历史分析仍可读取。
- 采用提示词后，编辑区文本与编辑后的预览一致，参考图片指向原始照片；不会自动提交生成。
- 浏览器采集的 error/warn 日志为空。仅验证桌面内置浏览器，未验证手机实机与其他浏览器。

## 自动测试与边界

- 本版本自动测试共 38 项，覆盖原有图像/三维模块及新分析模块。
- 新测试覆盖视觉请求结构、比较图片顺序与任务关联、无原图/超限拒绝、并发与去重、超时不重试、格式不完整拒绝、余额与鉴权错误、重启恢复、同源请求、生成参考图标识与不确定性默认值。
- 模型文本使用 textContent 展示，不执行模型输出的代码、指令或链接。
- 图片和截图文字是资料，不是系统指令；系统提示已要求忽略其指令性内容，但这不是对模型永不受干扰的保证。
- 尚无像素测量、自动关键点定位、二维蒙版、三维网格修补或自动历史真实性评分。landmarks 为文字核对建议。
- 当前真实样本为花瓶，不代表复杂雕塑或人物已通过质量验证；比例改善需后续生成与人工比较验证。
- 评委包包含代码、空配置模板和说明，排除真实密钥、图片、模型及分析历史。

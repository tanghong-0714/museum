# 拾遗：图像与三维阶段运行验收（R11）

## R11 新增验收项

四视角为俯视、仰视、左侧、右侧，每组 4 次生图调用，支持逐张重做。顶部底部为推测；实际送入 Tripo 的是复原主图＋左右图，上下图仅供审阅。等待期间有扫描、阶段和已等待时长；建模时出现由散到聚的轮廓粒子，真实 GLB 载入后切换。粒子为等待效果，不是提前返回的三维几何。实际验证与质量边界见 `四视角与等待动效验证_R11.md`，下方 R10 为历史描述。

## R10 当前验收路径

打开 `/images`，点击大上传区上传一张破损照片 → 自动分析并生成提示词 → 阅读后点击生成复原图 → 满意后直接建模，或先生成四视图、检查四个方向，再点击用四视图建模。首页无文物名称和任务管理；作品库只显示完成的三维模型。

四视图为 Tripo 原生生成，会额外产生用量；不可见背面为推测。未完成内容仅作 24 小时缓存，已完成模型的来源资料保留。当前验证范围见 `上传与四视图验证_R10.md`，下方旧版按钮与任务管理说明仅作历史记录。

本版本展示“破损照片 → AI 复原方案 → 人工确认 → Tripo 三维重建 → 补全示意与成品图导出”。人物雕塑等缺损部位的生成结果属于数字复原推测。

## 运行步骤

1. 安装 Node.js 24.11 或更新版本。
2. 解压源码包，复制 .env.example 为 .env。
3. 填入自己获授权的 LK_IMAGE_API_KEY。Tripo 功能另填 TRIPO_API_KEY；图片分析另填 DEEPSEEK_API_KEY。
4. 双击启动工作台.cmd，或在目录中运行 npm start。不需要 npm install。
5. 打开 http://127.0.0.1:4317/images 。

源码包不含作者的真实密钥、参考图片或生成历史。未配置密钥时页面可打开，但不会伪装为已接通或已生成。

R07 采用深色工作台：左侧输入与参数、中间图像/三维视口、右侧方案与资产。图像服务检查在页面右上角的服务状态中展开。三维页面用右侧页签切换补全标记、模型资产与任务详情；视口右上角可进入专注查看。照片点击可放大，Esc 关闭。手机底部可快速跳转参数、预览和资产区域。

## 建议验收顺序（R08）

1. 上传破损照片，确认自动分析开始；无需手动选择类别或填写结构假设。
2. 等待修复提示词自动显示，检查包含缺损、修复方法、保留特征与推测限制。
3. 阅读后点击“生成复原图”，应直接提交，不再要求点采用或二次确认。
4. 满意后点击“满意，开始建模”，应直接提交当前图并进入三维页。
5. 验证模型旋转、GLB 下载、PNG 导出与人工示意标记。
6. 刷新页面，提示词修改应保留且不会重复分析/生成。
7. npm test 使用模拟响应，不消耗额度。独立测试与真实分析验证范围见流程简化验证_R08.md。

鉴权成功不能代替实际生成验证。真实出图的效果、耗时和费用取决于服务商与参数。

## 当前边界

- 当前中转服务不支持蒙版，不能承诺只修改圈定区域或原像素不变。
- 每请求输出 1 张，最多同时执行 1 个任务，不自动重复提交。
- 超时或断线时任务可能仍在处理，先查任务号或后台记录再决定是否新建。
- 上传照片会自动产生 DeepSeek 分析用量；“生成复原图”和“满意，开始建模”分别提交收费任务，按钮含义已明确。
- 三维高亮为人工球形范围示意，不是精确补片；原图二维高亮编辑器尚未实现。
- 成品 PNG 来自当前 GLB 视角渲染，单张照片不能证明背面和内部结构。
- 服务仅监听 127.0.0.1，不是公网多用户版本。

验证记录见三维建模验证记录.md及生图接入验证记录.md；早期 Tripo 认证记录见连通测试记录.md。打包请使用 npm run package，Git 忽略规则不能保护任意手工压缩包。

## 历史验收记录（R04–R07，手动流程已由 R08 取代）

## R04 新增验收项

1. 在生图页添加原图后，点击“分析原图 · 预览复原提示词”（会产生 DeepSeek 分析用量）。
2. 确认分析区列出实际使用的参考图片、可见特征、推测限制和提示词。
3. 修改预览提示词，采用后检查编辑区内容与图片；采用操作不应创建生图或建模任务。
4. 选择历史成功复原图，点击“对比原图 · 检查比例与细节”，核对原图/结果是否对应，再人工审阅疑点。
5. 刷新页面验证分析历史、当前会话预览草稿仍在。配置未填写时显示未配置，原有生图/建模可独立使用。

仅鉴权成功不代表视觉分析已成功；实测范围见 DeepSeek接入验证记录.md。精确关键点标定与原图二维蒙版仍不属于本版本功能。

## R06 新增验收项

1. 点击“修复另一件文物”，确认照片、要求、结构和采用的分析清空；切回原任务并刷新，草稿仍在。
2. 复原模式未选器物类别、未确认视角或假设时，预览显示待补信息，不能确认生成。
3. 已知生成结果原文件重新上传时，显示 AI 辅助图，原始来源优先；改名可以识别，但裁剪、压缩、重绘或外部 AI 图不保证识别。
4. 采用 AI 分析前填写本次结构判断；其他文物或其他原图的分析不能直接采用。
5. 免费预览显示实际发送的全部提示词，包含器物类别、视角与结构要求。只有确认生成才创建收费任务；请求变化后需要重新预览。
6. 当前文物未选方案时，页面的“进入三维建模”按钮阻止误用其他文物方案。三维页仍应核对明确显示的来源图。
7. 版本列表可切换当前文物与全部记录；旧记录保留，缺失的历史完整提示词会如实说明。

草稿仅保存在当前浏览器，生成记录保存在项目 data/，不提供跨设备任务同步。R06 本轮仅进行 43 项模拟测试与浏览器交互验证，未新建收费任务；未证明真实模型的复原质量已提升。详见复原流程验证_R06.md。

## R07 布局与交互验收

1. 切换图像页右侧 AI 分析/版本，确认中间原图和复原图不消失。
2. 版本范围切换“全部文物”，按名称或要求搜索，点击记录只更新预览，不产生新收费任务。
3. 切换“并排/原图/复原图”；进入专注查看后左右面板隐藏，Esc 恢复。
4. 点击免费预览，核对原始参考与完整提示词；未点击确认生成不应新增任务。
5. 三维页右侧查看历史资产、标记和详情。切换历史模型时核对来源提示，切换材质或复位视角。
6. 打开点选标记后切换资产页签，点选状态应关闭；进入专注模式也会关闭标记。
7. 手机宽度下检查纵向布局与底部快捷入口。测试已覆盖内置浏览器 390×844，未冒称真机验证。

R07 只借鉴可见交互结构，没有接入 Tripo 网页的私有接口。右侧模型来源缩略图是生成时的输入图，不是新增渲染缩略图。本轮未新增收费任务，完整记录见工作台改版与REA记录_R07.md。
